Local Post Hub

Uses YouTube API Services

Local Post Hub is a personal, self-hosted tool that runs only on its owner's computer. It lets the owner upload their own videos to their own YouTube channel, and publish their own posts to their own TikTok, Facebook and Instagram accounts, using each platform's official API.

For YouTube it uses the YouTube API Services (YouTube Data API v3) to upload videos the owner chooses and to read the owner's channel name. It has no other users and is not offered to the public.

By using the YouTube features you agree to the YouTube Terms of Service. See our Privacy Policy and Terms of Service.
